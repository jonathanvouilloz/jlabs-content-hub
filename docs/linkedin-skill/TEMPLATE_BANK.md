# LinkedIn Post Template Bank
> Source : analyse de 50 + 160 posts top-performing d'influenceurs LinkedIn (Copyblogger, juin 2025 + Taplio/Shield 2025)
> Usage : référence pour le skill `linkedin-weekly-posts` — sélectionner les templates les plus adaptés au contenu + voix du projet

---

## Architecture du système

```
TEMPLATE (structure + hook pattern)
    +
VOICE PROFILE (ton, registre, vocabulaire du projet)
    =
POST FINAL (adapté au contenu ET au client)
```

## A — LISTICLE

> Posts à liste numérotée. Valeur immédiate, très partagés. Fonctionnent pour tous les secteurs.

### A1 — "X compétences/conseils que tout le monde devrait connaître"
**Hook pattern :** `Comment devenir indispensable en [domaine]. X [compétences] sous-estimées :`
**Structure :**
```
[Hook : comment devenir X en Y]

[Compétence/conseil 1]
↳ 1-2 phrases d'explication

[Compétence/conseil 2]
↳ 1-2 phrases d'explication

[... jusqu'à N]

La meilleure façon d'[accomplir X] ?
Devenir [Y].

[CTA share]
```
**CTA type :** Repost
**Audience :** Large
**Fonctionne pour :** Services B2B, expertise technique, RH, coaching
**Ton compatible :** Pro, neutre, accessible
**Source :** Template #2 (Colby Kultger)

---

## K — Formules Copywriting Fondamentales

> Ces formules ne sont PAS des templates autonomes — ce sont des **overlays** à appliquer sur n'importe quelle structure A→J pour maximiser l'impact. Le skill doit en choisir une par post selon l'objectif.

---

### K1 — Formule AIDA
**Quand l'utiliser :** Post de fond avec CTA clair. Fonctionne sur A, C, F.
**Mécanisme :**
- **A**ttention → hook qui brise une croyance commune
- **I**nterest → éléments concrets qui maintiennent l'intérêt
- **D**esire → teaser de nouvelles possibilités tangibles
- **A**ction → invitation à changer de mindset + CTA

**Template :**
```
Il est impossible de [atteindre objectif commun] sur/avec [plateforme/outil] aujourd'hui.

Voici ce qui est possible :
- On peut [action spécifique] pour [atteindre objectif précis].
- On peut [action spécifique] pour [atteindre objectif précis].
- On peut [action spécifique] pour [atteindre objectif précis].

Ça ne prend que [investissement de temps réaliste].

Mais en [délai court], vous aurez :
- [Résultat désiré]
- [Résultat désiré]
- [Résultat désiré]

Ne dites plus : "Je veux [objectif commun] aujourd'hui"

Dites plutôt : "Je veux [action quotidienne précise] aujourd'hui"

Choisissez [nouvelle stratégie] plutôt que [stratégie commune mais moins efficace].
```

---

### K2 — Formule PAS (Problem → Agitate → Solve)
**Quand l'utiliser :** Posts émotionnels, pain points forts. Parfait pour C1, D1, H1, H3.
**Mécanisme :**
- **P**roblem → poser le problème clairement
- **A**gitate → faire mal — creuser la blessure, intensifier le désir de solution
- **S**olve → soulager la tension avec un remède concret

**Template :**
```
[Fait impressionnant et relatable].

[Fait qui renforce le premier].

Voilà pourquoi [on peut / on doit faire X].

Mais à cause de [ces faits], [une conséquence négative peut se produire].

[Nommer la conséquence]. [Brève explication de sa pertinence].

Alors comment [résoudre ce problème] ?

[Nommer la solution]. [Brève explication].

X conseils/questions/étapes pour commencer :
- [Conseil 1]
- [Conseil 2]
- [Conseil 3]
- [Conseil 4]

Prenez [durée] pour [suivre ce conseil] et vous allez [bénéfice clé].
```

---

### K3 — Slippery Slide (effet toboggan)
**Quand l'utiliser :** N'importe quel post. Technique de rédaction pure, pas une structure.
**Mécanisme :** Les premières phrases sont ultra-courtes. Mots simples. Phrases incomplètes. Le lecteur est 5 lignes plus loin avant qu'une phrase dépasse 6 mots. Ensuite, le hook est posé.

> "Le seul objectif de la première phrase est que le lecteur lise la deuxième. Et la deuxième doit le faire lire la troisième." — Joseph Sugarman

**Application :**
```
[Concept court]. [Résultat court].

Ce n'est pas [concept] qu'on veut.
C'est [désir plus profond].

Pourtant...

[Croyance commune malgré tout].

Malgré [désir profond], beaucoup se laissent piéger.

[Développement du propos — ici on peut s'allonger, le lecteur est accroché]
```
**Règles :**
- Phrases 1 à 5 : max 6 mots chacune
- Zéro mot de plus d'une syllabe si possible dans les 3 premières lignes
- Phrases incomplètes acceptées — elles créent du rythme
- Utiliser des ellipses (`...`) ou des retours à la ligne pour forcer le défilement

---

### K4 — Emprunt de crédibilité
**Quand l'utiliser :** Quand le sujet est dense ou technique. Augmente la confiance du lecteur dans votre analyse.
**Mécanisme :** Citer une source reconnue (expert, étude, marque), expliquer son accomplissement, puis extraire la leçon applicable.

**Template :**
```
[Nom de la personne/organisation] a [accompli quelque chose de remarquable] avec [sujet/produit].

Voici comment [ils/elle] abordent [compétence spécifique] :

1. [Conseil pratique tiré de leur contenu/travail]
2. [Conseil pratique]
3. [Conseil pratique]
4. [Conseil pratique]

Lien vers [contenu complet / ressource] : [lien]
```
**Note :** La crédibilité empruntée doit être réelle — jamais inventer une source. L'accomplissement cité doit être vérifiable et impressionnant ("vendu 4 millions d'exemplaires").

## Règles d'adaptation à la voix du projet

Chaque template doit être filtré par le **voice profile** du projet avant génération :

### Registre
- `tutoiement` → transformer tous les "vous" en "tu", ton direct et pote
- `vouvoiement` → maintenir le vouvoiement, ton pro mais humain
- `neutre` → "on" majoritairement, éviter les adresses directes

### Ton
- `premium/expert` → supprimer les CTAs "likez et commentez", focus sur la valeur seule
- `accessible/grand public` → simplifier le vocabulaire, analogies du quotidien
- `humoristique` → ajouter touches d'autodérision, formulations inattendues
- `institutionnel` → retirer les opinions trop tranchées, privilégier faits + chiffres

### Exemples réels du projet
Si des posts publiés existent dans le hub pour ce projet (`type=linkedin, status=published`) :
→ Les analyser pour en extraire les patterns de phrase, le registre effectif, les sujets qui ont performé
→ Priorité à l'exemple réel sur la règle théorique
