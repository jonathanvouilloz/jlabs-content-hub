```
[Histoire personnelle où vous avez vécu cette réalité]

[Résolution : comment vous avez évité ou corrigé le problème]

Les 3 actions concrètes qui ont fait la différence :
1. Action + explication
2. Action + explication
3. Action + explication

[Présentation courte de vous et votre spécialité]
```
**CTA :** Présentation + engagement | **Audience :** Niche | **Secteurs :** Santé, bâtiment, juridique, marketing

### H3 — Attente controversée : juste ou pas ?

```
[Hook : question divisive]

[Anecdote : comment vous avez vu cette attente impacter des gens]

3 façons d'aller mieux :
→ Action 1 / → Action 2 / → Action 3

```
**CTA :** Débat | **Audience :** Large | **Secteurs :** RH, management, service client, dynamiques relationnelles
