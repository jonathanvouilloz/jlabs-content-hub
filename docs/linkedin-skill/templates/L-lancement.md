# Catégorie L — LANCEMENT / ANNONCE
> Posts pour créer de l'anticipation avant un lancement, une sortie, un événement.
> À utiliser ponctuellement — réserver aux vrais moments clés.

---

### L1 — Anticipation avant lancement
**Hook :** `Je suis [émotion]. C'est une grande [période]. Le [date], je lance [produit/service].`
```
[Hook : émotion + date + annonce]

Au départ, les choses ne se sont pas passées comme prévu :
- Défi rencontré
- Défi rencontré
- Défi rencontré

[Anecdote ou fait sur les difficultés passées]

Je pensais que ça n'arriverait pas.

Mais maintenant, c'est prêt.

C'est fait pour être votre [solution désirée].
C'est ce que j'utilise pour [atteindre l'objectif partagé].
C'est ce dont j'avais besoin quand je galérais.

Ça vous aide à [bénéfice 1], [bénéfice 2] et [bénéfice 3].

Rejoignez-moi le [date] pour [événement].
À [heure] — et si vous participez, vous pouvez [incitation].

Lien d'inscription : [lien]
```
**CTA :** Inscription / événement | **Audience :** Communauté existante + prospects
**Secteurs :** Lancement produit, service, événement, formation
**Note :** L'histoire de la lutte initiale est essentielle — elle montre que le produit est né d'un vrai besoin vécu. Sans ça, le post ressemble à de la pub.
