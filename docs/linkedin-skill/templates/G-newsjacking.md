# Catégorie G — NEWSJACKING / Actu
> Réagir à une actualité pour surfer sur l'attention déjà créée. Nécessite réactivité + angle propre.

---

### G1 — Réaction actu directe
**Hook :** `[Événement en une phrase]. Voici ce qu'on a appris :`
```
[Hook : actualité en une phrase courte]

Ce qu'on a appris de cette annonce :
→ Point 1 / → Point 2 / → Point 3 / → Point 4

On va voir [autres acteurs] faire pareil — c'est énorme pour l'avenir de [secteur].

[Lien vers la source si pertinent]
```
**CTA :** Engagement / follow | **Audience :** Large | **Secteurs :** Tech, marketing, tous secteurs avec actu fréquente
**Note :** Tout événement qui crée de la peur ou menace des emplois performe très bien.

---

### G2 — Ressource sur outil trending
**Hook :** `[N] prompts [outil trending] que [professionnels du secteur] devraient essayer aujourd'hui !`
```
[Hook : ressource + outil trending + promesse]

Que vous travailliez sur [tâche 1], [tâche 2] ou [tâche 3] — ces prompts vous facilitent la vie.

[Liste des prompts / astuces]

[CTA : follow + DM pour aide]
```
**CTA :** Follow + engagement | **Audience :** Large | **Secteurs :** Tous quand un outil nouveau arrive
**Note :** Capitaliser sur la sortie d'un outil dans les 48-72h pour maximiser le reach organique.
