# Templates Index — LinkedIn
> Lire ce fichier EN PREMIER. Sélectionner 1 catégorie par jour (L/M/V), puis lire uniquement le fichier catégorie correspondant dans `templates/`.

## Sélection par jour
- **Lundi 🟢** : poser problème, capter attention → K3 ou K2
- **Mercredi 🔵** : donner valeur, rediriger article → K1 ou K4
- **Vendredi 🟣** : angle alternatif, opinion, débat → K2 ou K3

> Toujours appliquer une formule K sur chaque post. Lire `templates/K-copywriting.md`.
